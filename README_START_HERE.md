# START HERE

This folder is a starter pack for a new Claude Code project.

## What to do
1. Create a new empty project folder on your computer.
2. Copy all files from this starter pack into that folder.
3. Open that folder in Claude Code.
4. Paste the contents of `FIRST_PROMPT.txt` into Claude Code.
5. Let Claude inspect the files and build Milestones 0–1.
6. Keep `CLAUDE.md`, `MEMORY.md`, `ROADMAP.md`, `MODEL_REGISTRY.md`, and `DECISIONS.md` in the project permanently.

## Important
Do not start by asking Claude to build the entire commercial app in one shot. The first goal is to prove that the system can reliably ingest and organize a large real photo library.

After Milestone 1 works, proceed to semantic search, then people matching, then curation, then album generation.

## Suggested first real-world test
Use a COPY/export of a photo folder containing a few hundred photos first. Once ingestion is stable, test 1,000–5,000 photos. The app must never modify the originals.

## Final destination
The project is intentionally staged, but the destination is a complete app: gallery → AI curation → editable album → print-ready pages/PDF → physical print ordering through a supported provider where feasible.
