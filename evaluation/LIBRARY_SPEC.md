# ספריית הבדיקה (I-008): מה לשים בה

טיוטה של אחראי בקרת איכות תמונות #1.

המטרה: ספרייה קבועה של תמונות אמיתיות. עליה מודדים כל שיפור, ולא על הדגמה.

## גודל
- התחלה: 1,000–3,000 תמונות **מקוריות**.
- בהמשך: 5,000 ואז 50,000 ומעלה, לבדיקות מהירות.

## חובה: תמונות מקוריות, לא תצוגות מקדימות
העתקה מהאייפון דרך תיקיית התמונות של Windows יצרה קבצים קטנים (~160 פיקסלים). קבצים כאלה לא מתאימים. דרכים מומלצות:
- באייפון: הגדרות ← תמונות ← "העברה ל-Mac או PC" ← **"שמור מקוריים"**, ואז ייבוא דרך אפליקציית "תמונות" של Windows;
- או הורדה מ-iCloud.com / OneDrive, שמורידים את המקור.

בדיקה מהירה: תמונה ממוצעת צריכה להיות מעל 1 MB, ברוחב של יותר מ-3,000 פיקסלים.

## מה צריך להיות בספרייה (גיוון מכוון)
| קבוצה | בערך | למה |
|---|---|---|
| כמה שנים (לפחות 4–5 שנים שונות) | פיזור טבעי | כיסוי לאורך זמן, ילדים שגדלים |
| אנשים קבועים (משפחה, בן/בת זוג, ילדים) | הרבה | שלב זיהוי האנשים |
| חיות מחמד | אם יש | אנשים וחיות = העיקר באלבום |
| טיולים (לפחות 2, אחד בחו"ל) | 150–300 | מקום, נופים שכן רוצים |
| אירועים: ימי הולדת, חגים, חתונה | 150–300 | "רגעים מיוחדים" |
| יום-יום רגיל | הרבה | רוב הספרייה האמיתית |
| סדרות צילום (burst), הרבה תמונות דומות | 10+ סדרות | בדיקת כפילויות ובחירת העותק הטוב |
| "זבל" אמיתי: צילומי מסך, קבלות, מסמכים, תמונות מטושטשות, צילומים בטעות | 10–15% | מה צריך לסנן |
| תמונות חשובות באיכות גרועה (מטושטשת אבל מרגשת) | כמה עשרות | שלא נאבד אותן |
| תמונות שקיבלת בוואטסאפ | קצת | בלי מידע EXIF, איכות נמוכה |

**אל תנקה מראש!** הספרייה צריכה להיראות כמו הגלריה האמיתית, עם כל הבלגן.

## פרטיות
- התמונות לא יוצאות מהמחשב.
- הספרייה של איתי (I-016) נבנית ומתויגת רק על המחשב שלו, ובאישורו.

## איך בונים (צעדים לבעל המוצר)
1. בוחרים תיקייה חדשה, למשל `D:\album-eval`, **מחוץ ל-OneDrive** אם אפשר.
2. מייבאים אליה תמונות מקוריות לפי הטבלה. לא צריך להיות מדויק.
3. באפליקציה: "בחר תיקייה" ← סריקה.
4. מודיעים למנהל הפרויקט. אחרי זה נבחר המדגם לתיוג המהיר (~300 תמונות, ~40 דקות).
